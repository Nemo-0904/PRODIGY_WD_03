# 👾 Tic-Tac-Toe Game

A classic **Tic-Tac-Toe** game implemented using **HTML**, **CSS**, and **JavaScript**, designed with a sleek dark theme and responsive layout.

---

## 🧩 Project Overview

This project recreates the traditional 3x3 Tic-Tac-Toe board where two players alternate turns to place their symbols (**X** and **O**).  
It automatically detects wins, ties, and provides a **Reset** button to start a new game.  
The focus was on clean UI, modular JavaScript logic, and intuitive user experience.

> 💼 Developed as part of my **Front-End Web Development Internship**, focusing on DOM manipulation, responsive design, and state management in JavaScript.

## 🕹️ Features

- **Dark Theme:** A modern dark interface for a clean visual experience.  
- **Responsive Layout:** Adjusts gracefully across devices and screen sizes.  
- **Game Logic:** Detects all 8 winning conditions (rows, columns, diagonals).  
- **Interactive UI:** Displays current player turn and final results.  
- **Reset Functionality:** Instantly clears the board to start a new round.
